# The 3D viewport is a Model inspector, not a spatial farm layout

Despite `GroundPlane`'s existing framing as a shared "plot of land"
backdrop (suggestive of a literal 3D floor-plan with printers placed in a
room), farm3d's 3D viewport is a Model inspector — for rotating/inspecting
a Model being Sliced or printed. Fleet status is a plain list/grid
dashboard, not a spatial view. A literal farm floor-plan was considered and
explicitly rejected for v1.
