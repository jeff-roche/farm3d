# farm3d manages a 3D-printer farm, not literal agriculture

farm3d's name and early UI (`Welcome`, `EditorShell`, `GroundPlane`) were
built around a literal farming domain — terrain, crops, buildings, a "plot
of land." The actual product is a 3D-printer print-farm management app:
connecting to and monitoring Printers, Slicing Models, and organizing a
Library, for hobbyists and print farm managers. Managing printers, slicing,
and viewing models are co-equal v1 pillars, not sequenced. The existing
agriculture-themed screens need a rework to match this; that rework is a
follow-up, not part of this decision.
