## Defects Discovered During F0

The canonical package recipe did not account for linuxdeploy's bundled legacy
`strip` rejecting modern `.relr.dyn` sections on CachyOS. The original exact
package command is the red reproduction. The AppImage-only `NO_STRIP=1` test
confirmed linuxdeploy's documented bypass, and commit `5952a44` applied it in
`justfile`; the exact package command then passed twice. No application code or
application-code test was needed.
